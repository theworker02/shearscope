# shearscope

Shear encode/decode helpers for scope payloads in pipelines.

**Site:** https://theworker02.github.io/shearscope/

## Install / run

```bash
git clone https://github.com/theworker02/shearscope.git
cd shearscope
node src/cli.js
node --test
```
